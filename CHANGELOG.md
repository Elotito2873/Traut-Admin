# Changelog

Todos los cambios relevantes siguen [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-14

### Added

- autenticación administrativa y MFA TOTP;
- dashboard, monitoreo Realtime y mapas OpenStreetMap;
- gestión de flota, rutas, paradas, tarifas y conductores;
- revisión de viajes e incidencias;
- RLS, auditoría e historial como propuestas SQL aditivas;
- Edge Function de invitación de conductores;
- CI, releases y empaquetado Linux/Windows/macOS/Web;
- temas claro/oscuro, accesibilidad y documentación operativa.
